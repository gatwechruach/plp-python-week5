# Week 5 Assignment: Hands-On Lab — Countdown, Guessing Game & Loop Patterns

- countdown.py — Uses a while loop to count down from 5 and print "Blast off!".
- guess_game.py — Uses a while loop to keep asking the user to guess until they get the secret number.
- spell_it_out.py — Uses a for loop to print each letter of a word on a separate line.

I would reach for a while loop when I don't know exactly how many times the loop needs to run and want it to continue until a condition changes. I would use a for loop when I need to go through each item in a collection or repeat something a known number of times.
